# Getting Started with Marky

*A quick tour of Marky's features*

## What is Marky?

Marky converts **structured YAML** into beautiful Markdown documents.

```go
fmt.Println("Hello from Marky!")
```

- Headings h1–h6
- Paragraphs with **bold** and *italic*
- Code blocks
- Lists, blockquotes, rules, links

> Simple things should be simple.
